# 2027 사업계획 EIS

2027년 사업계획을 **시현·검토용 대시보드**로 보여주는 독립 프로젝트입니다.
기존 `경영지원부문 KPI(EIS)` 시트·스크립트는 **전혀 건드리지 않습니다** — 코드 작성 방식만 참고했습니다.

| | 경영지원부문 KPI (기존) | 2027 사업계획 EIS (신규) |
|---|---|---|
| 목적 | 월 실적 마감·모니터링 | 계획 수립 결과 시현·검토 |
| 계정 | 회사 계정 | **asdblackwall@gmail.com** |
| 스프레드시트 | 기존 시트 | **새로 만드는 시트** |
| 파일 | `index.html` (레포 루트) | `2027_사업계획_EIS/` |

## 1. 설치 (asdblackwall@gmail.com 계정에서 15분)

> ⚠️ 이 단계는 **계정 로그인이 필요해 대신 해드릴 수 없습니다.** 아래대로 붙여넣기만 하면 됩니다.

1. `asdblackwall@gmail.com` 으로 로그인 → [sheets.new](https://sheets.new) 로 **새 스프레드시트** 생성
   - 이름 예: `2027 사업계획 데이터`
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 왼쪽 파일 목록에서 아래 3개를 만든다
   | Apps Script 파일 | 이 폴더의 파일 | 만드는 법 |
   |---|---|---|
   | `Code.gs` | `Code.gs` | 기본 생성된 `코드.gs` 내용을 지우고 붙여넣기 |
   | `Index.html` | `Index.html` | `＋ → HTML`, 이름을 **`Index`** 로 (대문자 I) |
   | `appsscript.json` | `appsscript.json` | 왼쪽 ⚙️ **프로젝트 설정 → "appsscript.json 매니페스트 파일 표시"** 체크 후 붙여넣기 |
4. 저장(Ctrl+S) → 함수 선택창에서 **`setupSheets`** 고르고 **실행**
   - 최초 1회 권한 승인 창이 뜬다 → 계정 선택 → *고급* → *(안전하지 않은 페이지)로 이동* → 허용
   - 시트 12개가 만들어지고 **데모 데이터**가 채워진다
5. **배포 → 새 배포 → 유형 ⚙️ 웹 앱**
   - 설명: `2027 사업계획 EIS v1`
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **링크가 있는 모든 사용자** (사내 공유면 조직 선택)
   - **배포** → 나오는 **웹 앱 URL** 이 대시보드 주소다
6. 시트의 데모 숫자를 **실제 2027 계획 숫자로 덮어쓰고** 웹앱을 새로고침하면 끝

### clasp(CLI)로 올리고 싶다면
```bash
npm i -g @google/clasp
clasp login                       # asdblackwall@gmail.com 으로 로그인
clasp create --type sheets --title "2027 사업계획 EIS"
cp Code.gs Index.html appsscript.json .   # 이 폴더 파일을 clasp 프로젝트로 복사
clasp push
clasp open                        # 편집기에서 setupSheets() 실행 후 배포
```

## 2. 시트 구조 — 숫자를 어디에 넣나

**단위 규칙: 시트 입력은 전부 `백만원`(정수).** 화면에서 표는 백만원, 그래프·KPI 카드는 억원으로 자동 환산합니다.
비율(%)·인원(명)은 그대로 씁니다.

| 시트 | 열 구성 | 설명 |
|---|---|---|
| `설정` | 키 / 값 / 설명 | 연도·제목·부서·게이트 사용여부 |
| `사업부_월별` | 사업부 / 구분 / 지표 / 1~12월 | **핵심 입력 시트.** 구분 = `계획` 또는 `전년`, 지표 = `sales` `cogs` `gp` `sgna` `op` |
| `전사_월별` | 구분 / 지표 / 1~12월 | 사업부로 안 쪼개는 항목(`orders` 수주액, `capex`) |
| `연도추이` | 지표 / 연도별 값 | 1행이 연도 헤더. 마지막 해가 계획연도로 강조된다 |
| `손익구조` | 레벨 / 항목 / 전년 / 계획 / 비고 | 레벨 `1`=대분류, `2`=하위항목. 민감도·손익분기 계산의 원가 구성도 여기서 읽는다 |
| `전제조건` | 구분 / 항목 / 단위 / 전년 / 계획 / 비고 | 환율·원자재·주택경기 등 계획의 가정 |
| `추진과제` | 부문 / 과제명 / KPI / 목표 / 담당 / 일정 / 기대효과 / 비고 | 행을 클릭하면 검토의견을 달 수 있다 |
| `투자계획` | 구분 / 투자명 / 금액 / 시기 / 목적 / 비고 | |
| `인원계획` | 부문 / 전년말 / 계획 / 비고 | |
| `시나리오` | 시나리오 / 매출액 / 매출총이익 / 영업이익 / 확률 / 전제 | Base·Best·Worst |
| `검토의견` | 키 / 항목 / 작성자 / 내용 / 작성일시 | 화면에서 자동 기록 — 직접 손댈 일 없음 |
| `직원` | 부서 / 사번 / 이름 / 사용여부 | 접근 게이트를 켤 때만 쓴다 |

### 손익 항등식 (입력할 때 지켜야 하는 것)
```
매출액 − 매출원가 = 매출총이익
매출총이익 − 판매관리비 = 영업이익
```
스프레드시트 상단 **`2027 사업계획` 메뉴 → 입력값 점검**을 누르면
이 항등식·연간 합계·시나리오 확률 합이 맞는지 한 번에 검사합니다.

### 사업부를 추가·삭제하려면
`사업부_월별` 시트에 그 사업부의 `계획`/`전년` × 5개 지표 = 10줄을 추가하면 됩니다.
화면의 탭·차트·표·범례는 시트에 있는 사업부를 그대로 따라갑니다 — 코드 수정 불필요.

## 3. 화면 구성

| 탭 | 내용 |
|---|---|
| **01 총괄** | 매출·매출총이익·영업이익·수주 KPI, **영업이익 증감 브릿지**(사업부별 기여), 연도별 추이(계획연도 강조), 사업부별 요약표, 매출 구성·이익률 비교 |
| **02 사업부별 계획** | 사업부 탭 전환 → KPI 4종, 월별 계획 vs 전년 차트, 월별 상세표(원가·판관비·이익률 포함) |
| **03 월별 계획** | 분기 카드, 사업부 스택 막대(칩으로 선택), 월간/누계 전환, 사업부×월 매트릭스 |
| **04 손익 구조** | 손익계산서(구성비·증감), 매출원가/판관비 구성 도넛, **민감도 시뮬레이션**(판가·재료비·물량 슬라이더), **손익분기 분석** |
| **05 전제·전략** | 시나리오 3종 + 확률 가중 기대값, 계획 전제조건, 핵심 추진과제(부문 필터·검토의견), 투자계획, 인원계획 |

시현 팁
- 브라우저 인쇄(Ctrl+P)하면 **5개 탭이 전부 펼쳐진 상태로 A4 가로 PDF** 로 저장됩니다.
- `설정` 시트 `AUTH_ON` 을 `Y` 로 바꾸면 사번·이름 입력 화면이 먼저 뜹니다(`직원` 시트로 대조).

## 4. 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 화면에 "데이터가 없습니다" | `setupSheets()` 를 아직 안 돌렸다. 편집기에서 1회 실행 |
| 그래프가 안 그려짐 | 사내망에서 `cdnjs.cloudflare.com` 이 막힌 경우. Chart.js 파일을 `chartjs.html` 로 프로젝트에 넣고 `Index.html` 의 `<script src=...>` 를 `<?!= include('chartjs') ?>` 로 바꾸면 된다 |
| 숫자가 화면과 시트가 다름 | 손익 4종(매출·원가·매출총이익·판관비·영업이익)은 **사업부 합계가 정본**이다. `전사_월별` 에 같은 지표를 넣어도 무시된다 |
| 수정했는데 화면이 그대로 | 웹앱은 **배포 시점 코드**로 동작한다. 배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포 |
| 검토의견이 저장 안 됨 | 로컬에서 HTML 파일을 직접 연 경우다(미리보기 모드). 웹앱 URL 로 접속할 것 |

## 5. 파일

```
2027_사업계획_EIS/
├─ Code.gs           서버 — 시트 읽기(buildData), 시트 초기화(setupSheets), 검토의견, 입력값 점검
├─ Index.html        화면 — 5개 탭, 13개 차트, 표·시뮬레이션 전부 포함(단일 파일)
├─ appsscript.json   매니페스트(시간대·웹앱 설정)
└─ README.md         이 문서
```

`Index.html` 은 **파일만 열어도** 데모 데이터로 화면이 보이도록 폴백을 갖고 있어,
설치 전에 구성만 먼저 확인할 수 있습니다.
