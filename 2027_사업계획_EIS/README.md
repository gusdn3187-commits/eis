# 2027 사업계획 EIS

2027년 사업계획을 **시현·검토용 대시보드**로 보여줍니다.
**구글시트에 숫자를 넣으면 화면이 그려지는 구조**이고, 구글시트 + Apps Script만으로 돌아갑니다.

기존 `경영지원부문 KPI(EIS)` 시트·스크립트는 **전혀 건드리지 않습니다** — 코드 작성 방식만 참고했습니다.

| | 경영지원부문 KPI (기존) | 2027 사업계획 EIS (신규) |
|---|---|---|
| 목적 | 월 실적 마감·모니터링 | 계획 수립 결과 시현·검토 |
| 계정 | 회사 계정 | **asdblackwall@gmail.com** |
| 스프레드시트 | 기존 시트 | **새로 만드는 시트** |

---

## 1. 설치 — 한 번만, 5분

붙여넣을 파일은 **`Code.gs` 와 `Index.html` 딱 2개**입니다.

### ① 스프레드시트 만들기
`asdblackwall@gmail.com` 으로 로그인 → [sheets.new](https://sheets.new) 에서 새 스프레드시트 생성
- 이름 예: `2027 사업계획`

### ② Apps Script 열기
상단 메뉴 **확장 프로그램 → Apps Script**

### ③ 파일 2개 붙여넣기

| Apps Script 파일 | 붙여넣을 내용 | 만드는 법 |
|---|---|---|
| `Code.gs` | `Code.gs` 전체 | 기본으로 있는 `코드.gs` 를 열어 **전체 선택(Ctrl+A) 후 삭제**하고 붙여넣기 |
| `Index.html` | `Index.html` 전체 | 왼쪽 **파일 옆 ＋ → HTML** → 이름을 **`Index`** 로 (대문자 I, 확장자는 자동) |

> `Index.html` 은 10만 자가 넘습니다. 붙여넣은 뒤 **맨 아래가 `</html>` 로 끝나는지** 한 번 확인하세요.

**Ctrl+S 로 저장.**

### ④ 시트 만들기 — `setupSheets` 실행
편집기 상단 함수 선택창에서 **`setupSheets`** 를 고르고 **▶ 실행**

- 처음 한 번 권한 승인 창이 뜹니다:
  **계정 선택 → 고급 → (안전하지 않은 페이지)로 이동 → 허용**
- 실행이 끝나면 스프레드시트에 **시트 12개**가 생기고 **데모 데이터**가 채워집니다

### ⑤ 웹앱으로 배포
**배포 → 새 배포 → 유형 ⚙️ → 웹 앱**

| 항목 | 값 |
|---|---|
| 설명 | `2027 사업계획 EIS v1` |
| 다음 사용자로 실행 | **나** |
| 액세스 권한 | **나만** (아래 *공유 범위* 참고) |

**배포**를 누르면 나오는 **웹 앱 URL**이 대시보드 주소입니다.

### ⑥ 끝 — 이제 시트에서 씁니다
스프레드시트로 돌아오면 상단에 **`2027 사업계획` 메뉴**가 생겨 있습니다.
(안 보이면 새로고침 한 번)

| 메뉴 | 하는 일 |
|---|---|
| **대시보드 열기** | 웹앱 주소를 기억할 필요 없이 바로 연다 |
| 시트 초기화 | 시트 틀 + 데모 데이터를 다시 만든다 |
| 데모데이터만 다시 채우기 | 숫자만 데모값으로 되돌린다 |
| **입력값 점검** | 손익 항등식·연간 합계·시나리오 확률이 맞는지 검사 |
| 코드 버전 확인 | 지금 붙여넣은 코드가 몇 버전인지 |

### 시간대 확인 (한 번만)
편집기 왼쪽 ⚙️ **프로젝트 설정 → 시간대**가 `(GMT+09:00) 서울` 인지 확인하세요.
다르면 바꿔 주세요 — 날짜 표기에 쓰입니다.

### 공유 범위 — 사업계획은 대외비입니다
기본은 **나만**으로 배포하시길 권합니다. 임원께 링크로 보여드릴 때만
**배포 → 배포 관리 → ✏️ → 액세스 권한 → 링크가 있는 모든 사용자**로 바꾸고,
이때는 `설정` 시트의 **`AUTH_ON` 을 `Y`** 로 두어 사번·이름 게이트를 함께 켜세요
(`직원` 시트에 등록된 사람만 열립니다).

## 2. 숫자 넣기 — 어느 시트에 무엇을

**단위는 전부 `백만원`(정수)로 입력합니다.** 화면에서 표는 백만원, 그래프·KPI는 억원으로 자동 환산합니다.
비율(%)·인원(명)은 그대로 씁니다.

| 시트 | 열 구성 | 설명 |
|---|---|---|
| `설정` | 키 / 값 / 설명 | 연도·제목·부서·게이트 사용여부 |
| `사업부_월별` | 사업부 / 구분 / 지표 / 1~12월 | **핵심 입력 시트.** 구분 = `계획` 또는 `전년`, 지표 = `sales` `cogs` `gp` `sgna` `op` |
| `전사_월별` | 구분 / 지표 / 1~12월 | 사업부로 안 쪼개는 항목 (`orders` 수주액, `capex`) |
| `연도추이` | 지표 / 연도별 값 | 1행이 연도 헤더. 마지막 해가 계획연도로 강조된다 |
| `손익구조` | 레벨 / 항목 / 전년 / 계획 / 비고 | 레벨 `1`=대분류, `2`=하위항목. 민감도·손익분기 계산의 원가 구성도 여기서 읽는다 |
| `전제조건` | 구분 / 항목 / 단위 / 전년 / 계획 / 비고 | 환율·원자재·주택경기 등 계획의 가정 |
| `추진과제` | 부문 / 과제명 / KPI / 목표 / 담당 / 일정 / 기대효과 / 비고 | 화면에서 행을 클릭하면 검토의견을 남길 수 있다 |
| `투자계획` | 구분 / 투자명 / 금액 / 시기 / 목적 / 비고 | |
| `인원계획` | 부문 / 전년말 / 계획 / 비고 | |
| `시나리오` | 시나리오 / 매출액 / 매출총이익 / 영업이익 / 확률 / 전제 | Base·Best·Worst |
| `검토의견` | 키 / 항목 / 작성자 / 내용 / 작성일시 | 화면에서 자동 기록 — 직접 손댈 일 없음 |
| `직원` | 부서 / 사번 / 이름 / 사용여부 | 접근 게이트를 켤 때만 |

**숫자를 고치면 웹앱 새로고침만으로 즉시 반영됩니다.** 다시 배포할 필요 없습니다.

### 지켜야 하는 손익 항등식
```
매출액 − 매출원가 = 매출총이익
매출총이익 − 판매관리비 = 영업이익
```
시트 메뉴 **`2027 사업계획` → 입력값 점검**을 누르면 이 항등식과
연도추이·월별 합계 일치, 시나리오 확률 합(100%)을 한 번에 검사합니다.

### 사업부를 추가·삭제하려면
`사업부_월별` 시트에 그 사업부의 `계획`/`전년` × 5개 지표 = **10줄**을 추가하면 됩니다.
화면의 탭·차트·표·범례는 시트에 있는 사업부를 그대로 따라갑니다 — 코드는 손대지 않아도 됩니다.

## 3. 코드를 새로 받았을 때

기능을 고쳐 새 `Code.gs` / `Index.html` 을 받으시면:

1. Apps Script 편집기에서 해당 파일 열기
2. **전체 선택(Ctrl+A) → 삭제 → 새 내용 붙여넣기 → 저장**
3. **배포 → 배포 관리 → ✏️(연필) → 버전: `새 버전` → 배포**
   (이 단계를 빼먹으면 웹앱 URL은 예전 코드 그대로입니다)
4. 대시보드 오른쪽 아래 **버전 표기**로 반영됐는지 확인

> 바뀐 파일만 붙여넣으면 됩니다. `Code.gs` 만 바뀌었으면 `Index.html` 은 그대로 두세요.
> 지금 버전은 **v1.0.0 (2026-08-24)** 이고, 시트 메뉴 *코드 버전 확인*으로도 볼 수 있습니다.

## 5. 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 화면에 "데이터가 없습니다" | `setupSheets()` 를 아직 안 돌렸다. 편집기에서 1회 실행 |
| 시트 상단에 `2027 사업계획` 메뉴가 없다 | 스프레드시트를 새로고침. 그래도 없으면 편집기에서 `onOpen` 을 한 번 실행 |
| 그래프가 안 그려짐 | 사내망에서 `cdnjs.cloudflare.com` 이 막힌 경우. Chart.js 파일을 `chartjs.html` 로 프로젝트에 추가하고 `Index.html` 의 `<script src=...>` 줄을 `<?!= include('chartjs') ?>` 로 바꾸면 된다 |
| 숫자가 화면과 시트가 다름 | 손익 4종(매출·원가·매출총이익·판관비·영업이익)은 **사업부 합계가 정본**이다. `전사_월별` 에 같은 지표를 넣어도 무시된다 |
| 코드를 고쳤는데 화면이 그대로 | 웹앱은 **배포된 버전**으로 돈다. 배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포 |
| 날짜가 하루 어긋난다 | 프로젝트 설정의 시간대가 서울이 아니다 |
| 검토의견이 저장 안 됨 | 파일을 직접 연 미리보기 상태다. 웹앱 URL 로 접속할 것 |

## 6. 파일

```
2027_사업계획_EIS/
├─ Code.gs      서버 — 시트 읽기(buildData), 시트 초기화(setupSheets),
│               검토의견, 입력값 점검, 시트 메뉴
├─ Index.html   화면 — 5개 탭, 13개 차트, 표·시뮬레이션 전부 포함(단일 파일)
└─ README.md    이 문서
```

`Index.html` 은 **파일만 열어도** 데모 데이터로 화면이 보이도록 폴백을 갖고 있어,
설치 전에 구성만 먼저 확인할 수 있습니다.
