# 2027 사업계획 EIS

2027년 사업계획을 **시현·검토용 대시보드**로 보여줍니다.
**구글시트에 숫자를 넣으면 화면이 그려지는 구조**이고, 구글시트 + Apps Script만으로 돌아갑니다.

기존 `경영지원부문 KPI(EIS)` 시트·스크립트는 **전혀 건드리지 않습니다** — 코드 작성 방식만 참고했습니다.

|---|---|---|
| 목적 | 월 실적 마감·모니터링 | 계획 수립 결과 시현·검토 |
| 계정 | 회사 계정 | **asdblackwall@gmail.com** |

**`20_상세계획` 열 구성**

```
장 | 절 | 원본쪽 | 항목 | 대분류 | 중분류 | 소분류 |
2020 … 2026(P) | 증감 | 2026 1월 … 2026 12월 | 2027(P) | 2027 1월 … 2027 12월
```

- **`항목` 열(D)이 화면에 뜨는 이름**입니다. 대/중/소분류는 원문의 계층을 그대로 둔 것입니다.
- **연도 열은 개수도 연도도 자유입니다.** 1행 헤더에 `2027(P)` 처럼 네 자리 연도로만 적어 두면
  코드가 위치를 알아서 찾습니다. 월 열은 `2027 3월` 처럼 **연도 + 월**로 적습니다.
- 그래서 **내년에 2027년판 상세자료를 받으면 헤더의 연도만 고쳐 붙여넣으면** 그대로 돌아갑니다.
- `2027(P)` 와 `2027 1~12월` 열은 **비어 있습니다.** 확정되는 대로 그 열만 채우시면
  화면의 연도 축과 표에 자동으로 붙습니다.

> 추출값은 원문과 대조해 확인했습니다.
> 2026(P) 매출액 244,054 · 매출원가 179,038 · 매출총이익 65,016 ·
> 영업이익 21,040 · 당기순이익 15,694 — 원문 수치와 모두 일치합니다.

**숫자를 고치면 웹앱 새로고침만으로 즉시 반영됩니다.** 다시 배포할 필요 없습니다.

### 2026년 자료를 그대로 붙여넣으실 때
`01_손익요약` `02_월별손익` `03_부문별추이` … 모든 시트의 **마지막 연도 열이 2027(P)** 입니다.
2026 사업계획서의 표를 그대로 복사해 오시고, **오른쪽에 2027 열 하나만 더** 채우시면 됩니다.
연도 헤더(1행)를 바꾸시면 화면의 표·그래프 축도 그대로 따라갑니다 — 코드는 손대지 않습니다.

### 계획 전제조건 — `12_전제조건`

원문 **「1. 사업계획 수립 주요 가정」** 표를 그대로 옮겨 두었습니다.
구분은 `수익성` `거시` `판관비` `인건비` `금융` `지분법` `투자` 일곱 가지이고,
`05 시장·동종사` 탭 맨 위에 표로 뜹니다. 계획의 근거를 한 장에서 설명할 때 쓰시면 됩니다.

### 시나리오 탭이 쓰는 전제 — `09_민감도가정`

슬라이더는 **계획 대비 증감이 아니라 실제 수준**을 움직입니다.
예를 들어 수율 슬라이더를 93 → 94 로 올리면, 자사 제조원가 1,022억의 1%가 절감됩니다.

| 키 | 변수 | 기준값 | 노출금액 | 계산 방식 |
|---|---|---|---|---|
| `sales` | 매출 달성률 | **100%** | 2,553억 | 달성률 1%p = 매출 1% 변동 |
| `yield` | 수율 | **93%** | 1,022억 | 수율 1%p 개선 = 자사 제조원가 1% 절감 |
| `fx` | 환율 | **1,400원** | 650억 | 환율 변동분 ÷ 1,400 을 수입 매입액에 적용 |
| `wage` | 임금인상률 | **3.2%** | 415억 | 인상률 1%p = 인건비 1% 증가 |
| `expense` | 판관 경비 | **258억** | 258억 | 금액 자체를 직접 움직임 |
| `_var_rate` | 변동원가율 | – | 62% | 매출이 1% 늘 때 원가가 따라 늘어나는 비율 |
| `_export` | 수출액 | – | 60억 | 환율이 매출에 주는 영향 계산용 |

**기준값(C열)이 사업계획에서 정한 값**입니다. 이 값을 바꾸면 화면의 기준선도 함께 움직입니다.
`_` 로 시작하는 2줄은 계수라 슬라이더에 나오지 않습니다.

화면을 처음 열면 **모든 변수가 계획 기준값**이고, 이때 토네이도 차트는
*각 변수를 한 단위씩 움직였을 때의 영업이익 영향*을 보여줘 어느 변수가 가장 민감한지 알려줍니다.
슬라이더를 하나라도 움직이면 실제 시나리오 영향으로 바뀝니다.

### 지켜야 하는 손익 항등식
```
매출액 − 매출원가 = 매출총이익
매출총이익 − 판매비와관리비 = 영업이익
연간 계획값 = 1~12월 합계
매출액 = 매출 부문(SW·수전·비데·타일·BK·케어·임대) 합계
```
시트 메뉴 **`2027 사업계획` → 입력값 점검**을 누르면 세 가지를 한 번에 검사합니다.

### 품목·부문을 추가·삭제하려면
`02_월별손익`에 중분류(부문) 한 줄과 그 아래 소분류를 넣으시면
화면의 표·스택막대·범례가 시트를 그대로 따라갑니다. 코드는 손대지 않아도 됩니다.
단, **`매출원가` 행보다 위에 있어야** 매출 부문으로 인식합니다.

2. **Ctrl+A → 삭제 → 새 내용 붙여넣기 → 저장**
3. **배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포**
4. 대시보드 오른쪽 아래 **버전 표기**가 바뀌었는지 확인

바뀐 파일만 붙여넣으면 됩니다. `Code.gs` 만 바뀌었으면 `Index.html` 은 그대로 두세요.

> **입력한 숫자는 사라지지 않습니다.**
> 코드를 붙여넣는 것은 *프로그램만 교체*하는 일이고, 숫자는 구글시트에 따로 있습니다.
> 시트를 다시 만들 필요도 없습니다.
>
> 새 코드가 **새 시트를 필요로 할 때만** 시트 메뉴의 **`시트 점검·보강`** 을 한 번 누르세요.
> 없는 시트만 만들고 **이미 값이 있는 시트는 건드리지 않습니다** (몇 번 눌러도 안전).
>
> `원본 데이터로 되돌리기` 만 입력값을 지웁니다 — 누르면 확인 창이 뜨니 실수로 지워질 일은 없습니다.

- 원본 데이터로 도는 동안에는 화면 맨 위에 노란 안내줄이 뜹니다. 확정 계획을 넣으면 사라집니다.

## 5. 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 화면에 "데이터가 없습니다" | `setupSheets()` 를 아직 안 돌렸다. 편집기에서 1회 실행 |
| 연도 열을 늘렸는데 그래프가 그대로 | 1행(연도 헤더)까지 같이 늘렸는지 확인. 화면은 **1행을 보고** 축을 만든다 |
| 시트 상단에 `2027 사업계획` 메뉴가 없다 | 스프레드시트를 새로고침. 그래도 없으면 편집기에서 `onOpen` 을 한 번 실행 |
| 그래프가 안 그려짐 | 사내망에서 `cdnjs.cloudflare.com` 이 막힌 경우. Chart.js 파일을 `chartjs.html` 로 프로젝트에 추가하고 `Index.html` 의 `<script src=...>` 줄을 `<?!= include('chartjs') ?>` 로 바꾸면 된다 |
| KPI 카드와 요약표 숫자가 다름 | 둘 다 `01_손익요약` 을 본다. 값이 다르면 그 시트가 `02_월별손익` 과 어긋난 것 — **입력값 점검**을 돌려볼 것 |
| 시나리오 탭 숫자가 이상함 | `09_민감도가정` 의 **노출금액**이 계획과 안 맞는다. 매출액·제조원가·인건비를 계획값으로 맞출 것 |
| 코드를 고쳤는데 화면이 그대로 | 웹앱은 **배포된 버전**으로 돈다. 배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포 |
| 날짜가 하루 어긋난다 | 프로젝트 설정의 시간대가 서울이 아니다 |
| 검토의견이 저장 안 됨 | 파일을 직접 연 미리보기 상태다. 웹앱 URL 로 접속할 것 |

## 6. 파일

```
2027_사업계획_EIS/
├─ Code.gs                  서버 — 시트 읽기(buildData), 시트 초기화(setupSheets),
│                           검토의견, 입력값 점검, 시트 메뉴, 원본 시드데이터
├─ Index.html               화면 — 7개 탭, 29개 차트, 표·시나리오 시뮬레이션 (단일 파일)
├─ 2027사업계획_구글시트양식.xlsx   구글시트로 가져올 시트 19장 (원문 상세자료 포함)
└─ README.md                이 문서
```

Apps Script에 **붙여넣을 파일은 `Code.gs` 와 `Index.html` 두 개**뿐이고,
`.xlsx` 는 구글시트로 **가져오기** 하는 파일입니다.

`Index.html` 은 **파일만 열어도** 원본 데이터로 화면이 보이도록 폴백을 갖고 있어,
설치 전에 구성을 먼저 확인하실 수 있습니다. (검토의견 저장만 웹앱에서 됩니다)
