# 2027 사업계획 EIS

2027년 사업계획을 **시현·검토용 대시보드**로 보여줍니다.
**구글시트에 숫자를 넣으면 화면이 그려지는 구조**이고, 구글시트 + Apps Script만으로 돌아갑니다.

기존 `경영지원부문 KPI(EIS)` 시트·스크립트는 **전혀 건드리지 않습니다** — 코드 작성 방식만 참고했습니다.

| | 경영지원부문 KPI (기존) | 2027 사업계획 EIS (신규) |
|---|---|---|
| 목적 | 월 실적 마감·모니터링 | 계획 수립 결과 시현·검토 |
| 계정 | 회사 계정 | **asdblackwall@gmail.com** |
| 스프레드시트 | 기존 시트 | **새로 만드는 시트** |

## 1. 설치 — 한 번만, 5분

붙여넣을 파일은 **`Code.gs` 와 `Index.html` 딱 2개**입니다.

### ① 스프레드시트 만들기
`asdblackwall@gmail.com` 으로 로그인 → [sheets.new](https://sheets.new) 에서 새 스프레드시트 생성
- 이름 예: `2027 사업계획`

### ② Apps Script 열기
상단 메뉴 **확장 프로그램 → Apps Script**

### ③ 파일 2개 붙여넣기

| Apps Script 파일 | 붙여넣을 내용 | 만드는 법 |
|---|---|---|
| `Code.gs` | `Code.gs` 전체 | 기본으로 있는 `코드.gs` 를 열어 **전체 선택(Ctrl+A) 후 삭제**하고 붙여넣기 |
| `Index.html` | `Index.html` 전체 | 왼쪽 **파일 옆 ＋ → HTML** → 이름을 **`Index`** 로 (대문자 I, 확장자는 자동) |

> `Index.html` 은 10만 자가 넘습니다. 붙여넣은 뒤 **맨 아래가 `</html>` 로 끝나는지** 한 번 확인하세요.

**Ctrl+S 로 저장.**

### ④ 시트 만들기 — `setupSheets` 실행
편집기 상단 함수 선택창에서 **`setupSheets`** 를 고르고 **▶ 실행**

- 처음 한 번 권한 승인 창이 뜹니다:
  **계정 선택 → 고급 → (안전하지 않은 페이지)로 이동 → 허용**
- 실행이 끝나면 스프레드시트에 **시트 12개**가 생기고
  **2026 사업계획서 원본 수치 + 2027년 계획안**이 채워집니다

### ⑤ 웹앱으로 배포
**배포 → 새 배포 → 유형 ⚙️ → 웹 앱**

| 항목 | 값 |
|---|---|
| 설명 | `2027 사업계획 EIS v2` |
| 다음 사용자로 실행 | **나** |
| 액세스 권한 | **나만** (아래 *공유 범위* 참고) |

**배포**를 누르면 나오는 **웹 앱 URL**이 대시보드 주소입니다.

### ⑥ 끝 — 이제 시트에서 씁니다
스프레드시트로 돌아오면 상단에 **`2027 사업계획` 메뉴**가 생겨 있습니다.
(안 보이면 새로고침 한 번)

| 메뉴 | 하는 일 |
|---|---|
| **대시보드 열기** | 웹앱 주소를 기억할 필요 없이 바로 연다 |
| **시트 점검·보강** | 없는 시트만 새로 만든다. **이미 값이 있는 시트는 건드리지 않는다** |
| 원본 데이터로 되돌리기 | 입력값을 지우고 **2026 사업계획서 기준 원본값**으로. **확인 창이 한 번 뜬다** |
| **입력값 점검** | 손익 항등식·월 합계·부문 합계가 맞는지 검사 |
| 코드 버전 확인 | 지금 붙여넣은 코드가 몇 버전인지 |

### 시간대 확인 (한 번만)
편집기 왼쪽 ⚙️ **프로젝트 설정 → 시간대**가 `(GMT+09:00) 서울` 인지 확인하세요.
다르면 바꿔 주세요 — 날짜 표기에 쓰입니다.

### 공유 범위 — 사업계획은 대외비입니다
기본은 **나만**으로 배포하시길 권합니다. 임원께 링크로 보여드릴 때만
**배포 → 배포 관리 → ✏️ → 액세스 권한 → 링크가 있는 모든 사용자**로 바꾸고,
이때는 `설정` 시트의 **`AUTH_ON` 을 `Y`** 로 두어 사번·이름 게이트를 함께 켜세요
(`직원` 시트에 등록된 사람만 열립니다).

## 2. 숫자 넣기 — 어느 시트에 무엇을

### 단위 규칙 — 이것만 기억하시면 됩니다

| 시트 | 입력 단위 |
|---|---|
| `02_월별손익` | **백만원** (2026 사업계획서 손익표와 동일) |
| 나머지 금액 시트 (`01_손익요약` `03_부문별추이` `04_품목별추이`) | **억원** |

**그래프는 전부 억원으로 자동 환산**해서 그립니다. 표는 원문 단위 그대로 보여줍니다.
비율(%)·회전율(회)·인원(명)은 어디서든 그대로 씁니다.

**숫자를 고치면 웹앱 새로고침만으로 즉시 반영됩니다.** 다시 배포할 필요 없습니다.

### 2026년 자료를 그대로 붙여넣으실 때
`01_손익요약` `02_월별손익` `03_부문별추이` … 모든 시트의 **마지막 연도 열이 2027(P)** 입니다.
2026 사업계획서의 표를 그대로 복사해 오시고, **오른쪽에 2027 열 하나만 더** 채우시면 됩니다.
연도 헤더(1행)를 바꾸시면 화면의 표·그래프 축도 그대로 따라갑니다 — 코드는 손대지 않습니다.

### 시나리오 탭이 쓰는 전제 — `09_민감도가정`

화면의 슬라이더는 이 시트의 **노출금액**에 변동률을 곱해 손익 영향을 계산합니다.

| 키 | 변수 | 노출금액이 뜻하는 것 |
|---|---|---|
| `sales` | 매출목표 | 2027년 계획 매출액 |
| `yield` | 수율 | 자사 제조원가 (수율 1%p 개선 = 그만큼 제조원가 절감) |
| `fx` | 환율 | 연간 수입 매입액(원화 환산) |
| `wage` | 임금인상률 | 판관 인건비 + 제조 노무비 |
| `expense` | 경비 | 판관비 중 경비 |
| `_var_rate` | 변동원가율 | 매출 1% 변동 시 원가가 따라 움직이는 비율 |
| `_fx_base` | 기준환율 | 2027 계획 전제 환율 (환율 10원 하락 = 10 ÷ 기준환율 만큼 매입원가 감소) |
| `_export` | 수출액 | 환율이 매출에 주는 영향 계산용 |

`_` 로 시작하는 4줄은 **계수**라 슬라이더에 나오지 않습니다. 나머지 5개만 화면에 뜹니다.
`기본변동` 열이 화면을 처음 열었을 때의 **제시 시나리오** 값입니다
(현재 : 매출목표 △1% / 수율 +1% / 환율 △10원 / 임금인상률 +1% / 경비 △1%).

### 지켜야 하는 손익 항등식
```
매출액 − 매출원가 = 매출총이익
매출총이익 − 판매비와관리비 = 영업이익
연간 계획값 = 1~12월 합계
매출액 = 매출 부문(SW·수전·비데·타일·BK·케어·임대) 합계
```
시트 메뉴 **`2027 사업계획` → 입력값 점검**을 누르면 세 가지를 한 번에 검사합니다.

### 품목·부문을 추가·삭제하려면
`02_월별손익`에 중분류(부문) 한 줄과 그 아래 소분류를 넣으시면
화면의 표·스택막대·범례가 시트를 그대로 따라갑니다. 코드는 손대지 않아도 됩니다.
단, **`매출원가` 행보다 위에 있어야** 매출 부문으로 인식합니다.

## 3. 코드를 새로 받았을 때

기능을 고친 새 코드를 받으시면 **붙여넣기 한 번**이면 됩니다. 다른 준비물은 없습니다.

1. Apps Script 편집기에서 해당 파일 열기
2. **Ctrl+A → 삭제 → 새 내용 붙여넣기 → 저장**
3. **배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포**
4. 대시보드 오른쪽 아래 **버전 표기**가 바뀌었는지 확인

바뀐 파일만 붙여넣으면 됩니다. `Code.gs` 만 바뀌었으면 `Index.html` 은 그대로 두세요.

> **입력한 숫자는 사라지지 않습니다.**
> 코드를 붙여넣는 것은 *프로그램만 교체*하는 일이고, 숫자는 구글시트에 따로 있습니다.
> 시트를 다시 만들 필요도 없습니다.
>
> 새 코드가 **새 시트를 필요로 할 때만** 시트 메뉴의 **`시트 점검·보강`** 을 한 번 누르세요.
> 없는 시트만 만들고 **이미 값이 있는 시트는 건드리지 않습니다** (몇 번 눌러도 안전).
>
> `원본 데이터로 되돌리기` 만 입력값을 지웁니다 — 누르면 확인 창이 뜨니 실수로 지워질 일은 없습니다.

## 5. 자주 겪는 문제

| 증상 | 원인 / 해결 |
|---|---|
| 화면에 "데이터가 없습니다" | `setupSheets()` 를 아직 안 돌렸다. 편집기에서 1회 실행 |
| 연도 열을 늘렸는데 그래프가 그대로 | 1행(연도 헤더)까지 같이 늘렸는지 확인. 화면은 **1행을 보고** 축을 만든다 |
| 시트 상단에 `2027 사업계획` 메뉴가 없다 | 스프레드시트를 새로고침. 그래도 없으면 편집기에서 `onOpen` 을 한 번 실행 |
| 그래프가 안 그려짐 | 사내망에서 `cdnjs.cloudflare.com` 이 막힌 경우. Chart.js 파일을 `chartjs.html` 로 프로젝트에 추가하고 `Index.html` 의 `<script src=...>` 줄을 `<?!= include('chartjs') ?>` 로 바꾸면 된다 |
| KPI 카드와 요약표 숫자가 다름 | 둘 다 `01_손익요약` 을 본다. 값이 다르면 그 시트가 `02_월별손익` 과 어긋난 것 — **입력값 점검**을 돌려볼 것 |
| 시나리오 탭 숫자가 이상함 | `09_민감도가정` 의 **노출금액**이 계획과 안 맞는다. 매출액·제조원가·인건비를 계획값으로 맞출 것 |
| 코드를 고쳤는데 화면이 그대로 | 웹앱은 **배포된 버전**으로 돈다. 배포 → 배포 관리 → ✏️ → 버전 `새 버전` → 배포 |
| 날짜가 하루 어긋난다 | 프로젝트 설정의 시간대가 서울이 아니다 |
| 검토의견이 저장 안 됨 | 파일을 직접 연 미리보기 상태다. 웹앱 URL 로 접속할 것 |

## 6. 파일

```
2027_사업계획_EIS/
├─ Code.gs                  서버 — 시트 읽기(buildData), 시트 초기화(setupSheets),
```

Apps Script에 **붙여넣을 파일은 `Code.gs` 와 `Index.html` 두 개**뿐입니다.

`Index.html` 은 **파일만 열어도** 원본 데이터로 화면이 보이도록 폴백을 갖고 있어,
설치 전에 구성을 먼저 확인하실 수 있습니다. (검토의견 저장만 웹앱에서 됩니다)
